How do downloads work?

The files come directly from the AirPort-RTW “Native AirPort build” workflow. “Download artifact” opens the GitHub download. You must be signed in to GitHub and have access to the repository. The downloaded ZIP contains the build artifact and the files provided by the workflow. The checksum applies to the Kext ZIP file inside the artifact.

Why is a build no longer available?

GitHub keeps artifacts for a limited time. Expired artifacts can no longer be downloaded; deleted artifacts are removed from this list. This page only shows successful beta-branch builds from the native AirPort workflow and their matching AirPortRTW artifacts. New builds appear after the next refresh.
