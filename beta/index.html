Wie funktioniert der Download?

Die Dateien kommen direkt aus dem „Native AirPort build“-Workflow von AirPort-RTW. Mit „Artifact herunterladen“ öffnest du den GitHub-Download. Du musst bei GitHub angemeldet sein und Zugriff auf das Repository haben. Der ZIP-Download enthält das erzeugte Build-Artifact einschließlich der vom Workflow bereitgestellten Dateien. Die Prüfsumme gehört zur darin enthaltenen Kext-ZIP-Datei.

Warum ist ein Build nicht mehr verfügbar?

GitHub speichert Artifacts nur für eine begrenzte Zeit. Abgelaufene Artifacts lassen sich nicht mehr herunterladen; bereits gelöschte Artifacts erscheinen nicht in dieser Liste. Die Seite zeigt nur erfolgreiche Builds von Beta-Branches aus dem nativen AirPort-Workflow und die zugehörigen AirPortRTW-Artifacts. Neuere Builds erscheinen nach der nächsten Aktualisierung.
