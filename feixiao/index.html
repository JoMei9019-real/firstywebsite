FEIXIAO / INSTALLATION GUIDE

From download
to connected.

Install Feixiao on your OpenCore system, one clear step at a time. Know where each file goes and how to check that it works.

Start the guideRelease 1.1.0 on GitHub ↗
OpenCorePCIex86_64Guide for 1.1.0

THE MATCHING PAIR

One release. Two files.

rtw88.kext
The driver. Loaded by OpenCore when macOS starts.
EFI / OC / Kexts
rtw88ctl
The control tool. Scan, connect and check your connection in Terminal.
/usr/local/bin

Always use both files from the same release.

BEFORE YOU BEGIN

Check your setup.

An existing OpenCore setup

This guide uses OpenCore injection on an x86_64 Hackintosh. The release targets macOS 11 or later; that build target is not a guarantee for every macOS and hardware combination.

A supported PCIe card

RTL8821CE is the most extensively tested. RTL8822BE, RTL8822CE, RTL8812AE and RTL8814AE are also listed by the project, with less validation. USB and SDIO adapters are unsupported.

01

Get the matching pair.

Download Feixiao-1.1.0.zip from the release assets and double-click it in Finder to extract it. Choose the packaged ZIP, rather than the source-code archives.

Download Feixiao 1.1.0

Inside the extracted Feixiao-1.1.0 folder:

rtw88.kextKeep the complete bundle together
rtw88ctlUse the matching utility

You do not need to build the driver or download firmware separately for this packaged release.

02

Mount and back up your EFI.

Mount the EFI partition that contains the OpenCore installation you actually boot from. Use your usual EFI mounting tool, or identify the partition in Terminal:

Terminal
diskutil list

Look for the EFI partition on the correct boot disk. Replace diskXsY below with its actual identifier from the list, then mount it.

Replace the partition identifier first
sudo diskutil mount diskXsY

Open the mounted volume in Finder. It should contain an EFI folder, with OC and config.plist inside. The volume name can vary.

Keep a way back.

Copy the entire existing EFI folder to a separate USB drive and verify that you can boot your known-working configuration from it before changing your main EFI. Keep the backup unchanged.

03

Put the Kext in OpenCore.

Copy the complete rtw88.kext bundle into EFI/OC/Kexts on your mounted boot EFI. A Kext may appear as one file in Finder; do not unpack its Contents folder.

EFIOCKextsrtw88.kext

Open EFI/OC/config.plist in your plist editor. In ProperTree, choose the regular OC Snapshot command, select the EFI/OC folder and review the resulting Kernel → Add entry.

ProperTree: how OC Snapshot works ↗

Use a regular snapshot for an existing setup. A clean snapshot rebuilds several configuration lists. Review all changes before saving.

On a narrow screen, scroll the table sideways to see all values.

If another driver such as AirPortRTW controls the same Wi-Fi card, disable its Kernel → Add entry for this test. Keep only one active driver for that card, then save config.plist.

04

Install the control tool.

Open Terminal. Type cd followed by a space, drag the extracted Feixiao-1.1.0 folder from Finder into Terminal, and press Return. You are now in the folder containing rtw88ctl.

Terminal
sudo mkdir -p /usr/local/bin
sudo install -m 755 ./rtw88ctl /usr/local/bin/rtw88ctl

Enter your macOS administrator password when sudo asks. Terminal does not display the password as you type. These commands install the utility; the Kext stays in your EFI.

The following commands use the full /usr/local/bin/rtw88ctl path so they work even when that folder is missing from your shell PATH.

05

Reboot and verify the pair.

Restart through the OpenCore configuration you just edited. Once macOS has started, open Terminal and compare the utility and loaded-driver versions.

Terminal
sudo /usr/local/bin/rtw88ctl version
Example for the 1.1.0 release
rtw88ctl:    1.1.0
Driver:      1.1.0
Channel:     Stable
Diagnostics: off
TX rate:     auto

Both version lines should match the release you installed. Diagnostics off and TX rate auto are the normal defaults. If no driver is found, use the troubleshooting section below.

06

Connect to your network.

Use rtw88ctl to turn the radio on and scan for networks. Scanning can take around 10 seconds.

Terminal
sudo /usr/local/bin/rtw88ctl power on
sudo /usr/local/bin/rtw88ctl scan -w 10

For a WPA/WPA2 network, replace YOUR_SSID and YOUR_PASSWORD with your network name and password. Keep the quotes.

Terminal
sudo /usr/local/bin/rtw88ctl connect 'YOUR_SSID' 'YOUR_PASSWORD'
sudo /usr/local/bin/rtw88ctl status

The connection state should become connected and the SSID should match your network. Open a website to check internet access. Your real password will be part of the connection command; do not share that command in screenshots or issue reports.

After sleep or recovery

Feixiao 1.1.0 intentionally leaves reconnection to userspace. An IDLE state after wake or driver recovery can be expected. Run the connect command again when needed.

IF SOMETHING GETS STUCK

Find the next check.

No rtw88 device found

Check that you booted the edited EFI, rtw88.kext is in EFI/OC/Kexts, and its Kernel → Add entry is enabled with the exact paths above. Confirm that your card is one of the supported PCIe models.

Tool and driver versions do not match

Replace both files with the pair from the same release and reboot. Use the full utility path shown above to avoid accidentally running an older copy.

Connected, but no internet access

Check the network interface and DHCP settings in macOS Network settings, then your router and access point. A driver state of connected confirms association, not that your network has supplied a working IP connection.

macOS no longer boots after the change

Boot your tested backup USB configuration and restore the previous EFI. To undo a working installation, disable the rtw88.kext entry in Kernel → Add and reboot before switching back to your previous Wi-Fi driver.

Collect a useful diagnostic log

Enable diagnostics, reproduce the problem, read the log, and then turn diagnostics off again. Include the chipset, macOS version and matching driver/tool versions in an issue; remove private details before sharing.

Terminal
sudo /usr/local/bin/rtw88ctl diag on
sudo /usr/local/bin/rtw88ctl log
sudo /usr/local/bin/rtw88ctl diag off
